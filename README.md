# E-commerce Product QA Bot

This project demonstrates a **Retrieve and Generate (RAG)** based question-answering system for nutrient recipe recommendation using **LangChain**, **FAISS**, and **DeepSeek -r1**.

The bot can answer questions about various nutrient requirements, such as calories, recipe preference, and other weight management related queries.

## 🛠️ Tech Stack

- **LangChain**: Framework for building applications with LLMs (Language Models).
- **FAISS**: Efficient similarity search library for vector-based search.
- **DeepSeek -r1**: Language model used to generate answers.
- **Streamlit**: Library for building interactive web applications.
